# American University Men's Basketball Analytics Database

## Overview
This project focused on designing a centralized basketball analytics database system to improve player performance tracking and coaching decision-making for the American University Men’s Basketball Team. The project combined SQL querying, relational database design, and sports analytics concepts.

## Tools Used
- SQL
- Relational Database Design
- ER Diagrams
- Database Normalization
- Sports Analytics

## Key Features
- Designed 8 normalized relational tables
- Stored 200+ player game-stat records
- Built SQL queries using joins, subqueries, and aggregate functions
- Developed efficiency-based player rating metrics

## Project Goals
- Improve organization of player and game data
- Support coaching and roster evaluation
- Centralize injury and performance tracking
- Create scalable basketball analytics infrastructure

## Repository Structure
- `dashboards/` database screenshots and analytics visuals
- `visuals/` ER diagrams and supporting graphics
- `code/` SQL queries and database scripts
- `presentation/` final presentation materials and documentation
